## 二、原视频分析结论

### 1. 结构与时长

- 12 个画面 + 结尾回到第 1 张，全部为硬切，无转场
- 每张停留 0.798s ≈ 24 帧 @30fps
- 每组的切换点：0.60s、1.40s、2.19s、3.02s、3.79s、4.59s、5.45s、6.22s、7.01s、7.84s、8.61s、10.40s

### 2. 背景音乐

- 纯 BGM，无人声；AAC 44.1kHz 立体声 99kbps
- BPM ≈ 75（脉冲周期 0.800s），重音每两拍一次（1.6s）
- 鼓点时刻：0.04 + 0.8k 秒
- **原片存在约 0.23–0.25s 的固定声画偏移**：画面比鼓点提前约 1/4 拍，推测是剪辑时音轨偏移或录屏延迟

### 3. 放大动效（重要）

用多尺度匹配测量，6 张原图都有缓慢推近，6 张转绘完全静止：

| 片段 | 实测放大倍数（首尾帧） | 段内逐帧差异 |
|---|---|---|
| 原图 COOL | 1.028 | 0.16 |
| 原图 PLAY | 1.040 | 0.84 |
| 原图 SURF | 1.016 | 0.21 |
| 原图 BLOOM | 1.044 | 0.35 |
| 原图 JOY | 1.028 | 0.29 |
| 原图 TRAVEL | 1.036 | 0.92 |
| 6 张转绘 | 1.000 | 0.02–0.08（仅压缩噪声） |

结论：原图段是 Ken Burns 缓推（约 2%–4%），转绘段是硬切后的完全静止，形成「动 → 静」的节奏对比。

## 三、成片方案（已交付）

### 交付文件

这两个文件在 `一键生成视频` 文件夹的**上一级**，如果移动文件夹，需要单独移动它们。

### 规格

| 项目 | 结果 |
|---|---|
| 分辨率 | 1080×1620（2:3） |
| 背景 | 纯黑 `#000000` |
| 帧率 | 30fps |
| 总帧数 | 320 帧（12×24 + 结尾页 32） |
| 时长 | 10.67s |
| 编码 | H.264 High + AAC 192kbps，faststart |
| 切换点 | 第 24/48/72/…/288 帧，每 0.8s 一次 |

### 画面处理

- 裁掉手机状态栏、小红书界面、点赞栏
- 裁掉图片左下角「视频原声 发同款」浮层（底部裁 92px，原图区域由 862×1152 裁成 862×1060）
- 图片等比居中放在画布上，不裁切
- 原图段：24 帧内 `1.00 → 1.04` smoothstep 缓动推近
- 转绘段：静止
- 结尾页：32 帧（1.07s），黑底 + 米色「结尾页」三个字，宋体

### 卡点处理

- 音轨裁到第一个鼓点开始（原片约 0.04s）
- 成片实测切换点与鼓点误差 20–30ms（不到 1 帧）
- 验证结果：320 帧、切换点精确落在 24 帧边界、原图段缩放 1.036、转绘段 1.000

## 四、一键生成工具

### 目录结构

```
一键生成视频\
  素材\                 ← 放图片和 BGM
    01_原图.jpg
    01_转绘.jpg
    ...
    06_原图.jpg
    06_转绘.jpg
    结尾页.jpg
    bgm.m4a             ← 已内置原视频音轨，可替换
  输出\                 ← 每次生成带时间戳的成片
  生成视频.py            ← 核心脚本
  一键生成.bat           ← 双击运行
  配置.txt               ← 参数配置
  项目记录.md            ← 本文件
```

### 使用步骤

1. 把 13 张图片放进 `素材`：
   - 12 张对比图 + 1 张结尾页
   - 按文件名自然排序，**最后一张自动作为结尾页**
   - 推荐命名 `01_原图` / `01_转绘` … `06_原图` / `06_转绘` / `结尾页`
   - 文件名含「原图」→ 加推近；含「转绘」→ 静止；没有命名线索时按顺序 1、3、5…为原图
2. BGM 放在 `素材`，命名以 `bgm` 开头，支持 mp3 / m4a / wav / aac / flac / ogg
3. 双击 `一键生成.bat`，完成后自动打开 `输出` 文件夹
   - 也可以把任意素材文件夹直接拖到 bat 上，临时指定素材路径
4. 成片命名：`输出\成片_年月日_时分秒.mp4`

### 配置说明（配置.txt）

| 键 | 默认值 | 说明 |
|---|---|---|
| 每张帧数 | 24 | 30fps 下 24 帧 = 0.8s = 75 BPM 一拍 |
| 结尾页帧数 | 32 | 结尾页停留时长 |
| 推近幅度 | 0.04 | 原图放大 4%，填 0 关闭 |
| 画面宽 / 画面高 | 1080 / 1620 | 2:3 |
| 帧率 | 30 | |
| 音频起点 | 自动 | 自动找第一个鼓点；也可填秒数如 0.04 |
| 背景色 | 0,0,0 | RGB |

### 工具行为

- 自动估算 BPM 并打印；若与「每张帧数」对应的 BPM 相差超过 3，会提示调整
- 自动检测音轨第一个明显起音作为起点，让第一张图与第一拍同时出现
- 图片等比放入画布，不裁切；不同比例的图片会自动上下/左右留黑
- 结尾页同样等比放入，如提供 1080×1620 则满屏
- 生成失败时会在 `输出` 保留 `_ffmpeg_log.txt` 供排查

### 运行依赖（换电脑时注意）

- Windows + Python 3（`python` 命令需在 PATH 中）
- Python 包：`numpy`、`Pillow`、`imageio-ffmpeg`
- ffmpeg 由 `imageio-ffmpeg` 自带，无需单独安装
- 如缺少包：`pip install numpy pillow imageio-ffmpeg`

### 迁移说明

- 整个 `一键生成视频` 文件夹可以直接剪切/移动到任意位置
- 脚本用 `os.path.dirname(os.path.abspath(__file__))` 定位自身目录，bat 用 `%~dp0`，移动后不用改路径
- `素材\bgm.m4a` 已随文件夹打包，不会因移动丢失
- 注意：交付的两个成片 mp4 在上一级目录，不在工具文件夹内

## 五、本对话时间线

1. 用户上传原视频，要求分析内容、BGM 与卡点关系
2. 分析确认：6 组原图→转绘，BGM 75 BPM，每张 24 帧，原片有约 0.24s 声画偏移
3. 要求重新剪辑：6 组各 24 帧、卡点、6 组后加「结尾页」
4. 裁剪手机 UI，输出 1080×1920（9:16），卡点误差 20–30ms，结尾页 32 帧
5. 要求改成 2:3、黑底 → 输出 1080×1620
6. 用户询问原图是否有放大动效 → 实测确认原图段有 1.6%–4.4% 推近，转绘段静止
7. 要求在成片中加入该动效 → 原图段 1.00→1.04 smoothstep，转绘静止，重新导出
8. 要求做成一键生成工具 → 完成 `生成视频.py` + `一键生成.bat` + `配置.txt`，并用现有 13 张图实测通过
9. 用户决定移动整个工具文件夹，要求补一份记录文档 → 即本文件
