# 小画主页改造实施计划

## 一、概述

把"风格选择"页（`/styles`）改造为小画（draw-card）的新主页，取代旧主页（`/`）；新增"最近任务"页与"我的卡夹"独立页；移除"试试手气"。仅影响 draw-card 经验，fridge-magnet（冰箱贴）、body-book（认知书）保持不动。

已与用户确认的决策：
1. "再做一张"按钮 → 回到主页重新选风格。
2. "最近任务"页全部展示：成功图卡、运行中占位、失败态。
3. "我的卡夹"独立页 = 卡夹卡片列表（保留磁吸亚克力渲染）+ "选图定制"下单入口；移出兑换码/我的订单/联系客服等账户区。

## 三、后端改动（`server/index.js`）

### 3.1 放开 draw-card 多任务并行
- 保留 83 行 `VISITOR_RUNNING_JOB_LIMIT = 1`，紧邻新增 `const VISITOR_RUNNING_DRAW_CARD_JOB_LIMIT = 12;`（上限 12，足够 2-3 个会话并发，可按供应商并发调优）。
- 修改 `enforceVisitorRunningJobLimit`（10240 行）：按 `config.experienceType === "draw-card"` 选择上限；draw-card 用新常量，其余经验维持 1。
- 效果：draw-card 允许多会话并行；fridge-magnet/body-book 仍受 1 限制（不回归）。

### 3.2 新增 24h 最近任务接口
- 在 2330-2332 行（`/latest`）之后、2338 行（`/:sessionId`）**之前**注册（顺序关键，否则 `recent` 被 `:sessionId` 吞掉）：
  - `GET /api/draw-card/sessions/recent`（`requireWebAccount`），调用新增的 `listRecentDrawCardTasks(req.webAccount)`，返回 `{ tasks: [...] }`，失败返回 500 + 友好消息。
- 在 `readLatestAccountDrawCardSession`（11073 行）附近新增 `listRecentDrawCardTasks(account, { hours = 24 } = {})`：
  - 取 `Date.now() - 24h` 作为 cutoff（ISO 字符串）。
  - `listDrawCardSessions()` 后按 `accountOwnsPublicRecord(account, session)` + 经验类型 `draw-card` + `createdAt >= cutoff` 过滤。
  - 每个 session 调用 `synchronizeDrawCardSession` 拿最新 job 状态/结果，把每个 `item` 拍平为一条任务：`{ sessionId, order, jobId, styleId, styleName, status, errorMessage, result(经 toPublicPreviewResult), createdAt, updatedAt }`。
  - 按 `updatedAt` 倒序返回。
- 复用现有 `toPublicPreviewResult`（14886 行）保证与结果页展示一致（水印预览图 = `result.previewUrl`）。
- 无需改动的接口：`/api/public/clip-items`（卡夹页数据源）、`/api/draw-card/sessions/latest`。

## 六、假设与决策

- "最近任务"的"任务" = 会话内的单个 job（风格生成），页面以平铺网格展示 24h 内所有 job，与"最近生成"结果卡一致。
- "最近任务"排序按任务最近更新倒序（最新在前）。
- "我的卡夹"独立页排序沿用现有逻辑（`likedAt` 倒序，最新加入在前）。
- 卡夹页"选图定制"下单入口保留（商品详情 + 选图定制按钮 + 价格，复用 6170-6183 行）。
- draw-card 并行上限 12；fridge-magnet/body-book 仍为 1。
- 新主页本身没有上传区，生成入口沿用现有交互：主页点风格卡 → 弹窗"做同款" → 上传照片 → 生成。"试试手气"（随机+主体类型流）删除后不提供替代随机玩法。
- `/tasks`、`/clip` 路由为前端 SPA 内路由；服务端对非 `/api` 路径回退到 index 的现有机制无需改动。

## 七、实施顺序

1. 后端 3.1、3.2（并行放开 + 新接口），本地起服务联调接口。
2. 前端 4.1 路由与分发（让 `/tasks`、`/clip` 可到达）。
3. 前端 4.2 新主页头部 + 4.5 移除"试试手气"。
4. 前端 4.3 最近任务页。
5. 前端 4.4 卡夹独立页 + 4.6 旧主页收敛。

## 八、验证步骤

后端：
1. `GET /api/draw-card/sessions/recent` 新账号返回 `{ "tasks": [] }`，且未被 `/:sessionId` 吞掉。
