# 收款与邮箱验证码部署配置指南

## 当前收款模式：商户收款码 + 人工确认

项目当前不使用微信支付接口，因此不需要认证公众号，也不需要填写任何 `WECHAT_PAY_*` 或 `WECHAT_OAUTH_*` 参数。

用户提交订单后会看到商户收款码、订单号、应付金额和付款截止时间。管理员需在微信商户收款记录中核对到账金额及订单号，然后在管理后台“订单管理 → 订单详情”点击“确认已收款”。该操作会将订单转为待发货，并且仅首次操作时赠送点数、解锁原图下载。

收款码文件：

- 网站：`public/payment/wechat-merchant-collection.png`
- 小程序：`wechat-miniprogram/miniprogram/images/wechat-merchant-collection.png`

更换收款码时，请同时替换这两个文件，并使用同一个文件名。

详细操作与核账注意事项见 [冰箱贴收款上线清单](commerce-payments.md)。

## 邮箱验证码（腾讯云 SES）

邮箱验证码与收款模式无关。生产环境使用腾讯云 SES，不使用 SMTP。请在 `.env` 配置：

```env
EMAIL_CODE_LOG_ONLY=false
EMAIL_CODE_SECRET=单独生成的高强度随机密钥
TENCENTCLOUD_SECRET_ID=腾讯云CAM密钥的SecretId
TENCENTCLOUD_SECRET_KEY=腾讯云CAM密钥的SecretKey
TENCENTCLOUD_SES_REGION=ap-guangzhou
TENCENTCLOUD_SES_FROM_EMAIL=no-reply@你的已验证域名
TENCENTCLOUD_SES_TEMPLATE_ID=已审核通过的模板数字ID
```

参数获取方式：

| 参数 | 如何获得 |
| --- | --- |
| `EMAIL_CODE_LOG_ONLY` | 生产必须填写 `false`；本地调试可为 `true`，但会在接口响应和日志暴露验证码，不能部署到公网。 |
| `EMAIL_CODE_SECRET` | 自行生成且不与其他密钥复用的随机字符串；更换后尚未使用的旧验证码会失效。 |
| `TENCENTCLOUD_SECRET_ID` / `TENCENTCLOUD_SECRET_KEY` | 腾讯云控制台“访问管理 → 访问密钥 → API 密钥管理”创建的 CAM 子用户 API 密钥。只授予发送 SES 邮件的最小权限。 |
| `TENCENTCLOUD_SES_REGION` | 腾讯云 SES 控制台使用的地域；当前示例是 `ap-guangzhou`，以控制台实际地域为准。 |
| `TENCENTCLOUD_SES_FROM_EMAIL` | SES 控制台审核通过的完整发信邮箱。 |
| `TENCENTCLOUD_SES_TEMPLATE_ID` | SES 控制台中已审核通过模板的数字 ID；模板变量必须为 `code` 和 `minutes`。 |

部署前安装 SDK：

```bash
npm install tencentcloud-sdk-nodejs
```

配置完成并重启服务后，用非管理员邮箱测试注册或重置密码，确认邮件发送记录和收件箱均正常。
