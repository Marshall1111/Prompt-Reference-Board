# N1 打印设备量产与配置方案

> 状态：计划稿，等 N1 到手后按本文执行。
> 适用硬件：斐讯 N1（Armbian，系统跑在 eMMC）+ Canon SELPHY CP1500。
> 目标：把 N1 配置成插电即可自动接单打印的设备，并用 Windows EXE 完成首次配置，不再依赖 U 盘启动和路由器后台找 IP。

---

## 1. 目标与非目标

### 1.1 目标

- 系统继续跑在 N1 的 eMMC，不折腾 U 盘启动，不改 bootloader。
- Windows EXE 通过 SSH 配置 N1，不需要刷机、不需要管理员权限。
- EXE 支持「扫描设备」，不用每次去路由器后台找 IP。
- 支持保存多个 WiFi，并按优先级自动切换。
- 安装依赖可离线完成，不依赖 N1 现场访问外网下载。
- 配置完成后能自动上线，后台「设备库存」看到在线。
- 能自动接单、调用 CUPS 打印，不需要人工干预。

### 1.2 非目标

- 本阶段不做 U 盘启动系统。
- 本阶段不做 eMMC 批量刷机/克隆。
- 不让商户自己配置设备。
- 不改变现有线上商户和设备的绑定关系。
- 不把线上正在使用的设备 token 复用到新 N1。

---

## 2. 已确认的决策

| 项目 | 决策 |
| --- | --- |
| 系统位置 | N1 eMMC 里的 Armbian |
| 配置通道 | 网线 + SSH，PC 与 N1 在同一路由器 |
| 设备发现 | EXE 加「扫描设备」按钮，优先 UDP 广播发现 |
| WiFi 配置 | 商户 WiFi、家里 WiFi、手机热点全部保留 |
| WiFi 优先级 | 商户 300 > 家里 200 > 手机热点 100 |
| 安装方式 | 本地离线包 + 本地 apt 源，不依赖 N1 外网 |
| 打印机 | CP1500 在配置阶段就必须接上并开机 |
| 设备 token | 后台「设备库存」新建，逐台注入 |
| 商户绑定 | 设备上线后在后台绑定，或后续 EXE 增加绑定功能 |
| EXE 技术栈 | 待定，推荐 .NET WPF + SSH.NET；备选 Python + Paramiko |

## 3. 整体架构

```text
后台设备库存 / CSV
        │
        ▼
Windows EXE
  ├─ 扫描设备（UDP 广播 / 局域网扫描）
  ├─ SSH 登录 N1
  ├─ 上传离线包、print-agent、provision.sh
  ├─ 执行 provision.sh
  └─ 验证服务、CUPS 队列、心跳、WiFi
        │
        ▼
N1 eMMC Armbian
  ├─ CUPS + cp1500 队列
  ├─ print-agent.service
  ├─ 三个 WiFi 配置（按优先级自动连接）
  ├─ petpaint-discover.service（UDP 50000）
  └─ 心跳 → https://www.petpaint.top → 后台在线
```

## 4. 硬件与前置条件

### 4.1 硬件

- [ ] 斐讯 N1 一台，卖家已预装 Armbian 到 eMMC
- [ ] N1 12V 电源
- [ ] 网线一根
- [ ] Canon SELPHY CP1500 打印机 + 电源 + USB 数据线
- [ ] 相纸、色带
- [ ] Windows 10/11 电脑
- [ ] 可选：HDMI 线 + USB 键盘（救砖/首次登录用）
- [ ] 可选：手机热点（2.4GHz）

### 4.2 账号与权限

- [ ] N1 的 SSH 账号和密码
- [ ] N1 能通过网线从路由器获取 IP
- [ ] 后台管理员账号，能进入「设备库存」
- [ ] 首次登录如果强制改密，先在 HDMI 或 SSH 里完成一次

### 4.3 网络

- N1 插路由器 LAN 口，PC 连同一个路由器的 WiFi。
- PC 和 N1 必须在同一局域网。
- 首次制作离线包时，需要一次能访问 Debian 源和 SourceForge 的网络环境。
- 设备运行时只需要能访问 `https://www.petpaint.top`，不需要梯子。

## 5. 设备记录与 token 规则

1. 在后台「设备库存」新建一台设备，不要复用线上正在使用的设备 token。
2. 批量创建后导出 CSV，CSV 至少包含：

   ```csv
   deviceId,token,label,hardwareModel,printerName
   dev_xxx,64位令牌,N1-0001,n1,cp1500
   ```

3. EXE 选择一行后，必须标记该行已使用，防止重复注入。
4. 设备上线后再绑定商户。
5. 如果是替换线上设备：
   - 先停止旧设备的 `print-agent`
   - 后台解绑旧设备
   - 再绑定新设备
   - 不要让两个代理用同一个 token 同时运行

## 6. EXE 功能设计

### 6.1 页面结构

#### 页面 1：登录 / 扫描

- 「扫描设备」按钮
- 设备列表：主机名、IP、型号、是否已配置
- 手动输入 IP 作为兜底
- Armbian 用户名、密码
- SSH 首次连接显示指纹，确认后记住
- 提示：如果首次登录强制改密，需要先手动完成

#### 页面 2：网络配置

- WiFi 列表，支持添加多条
- 每条字段：
  - SSID
  - 密码
  - 优先级
  - 是否隐藏
- 默认优先级：
  - 商户 WiFi：300
  - 家里 WiFi：200
  - 手机热点：100
- 「测试 WiFi」按钮
- 可选：「使用电脑代理安装」开关
  - 电脑 IP
  - 代理端口（Clash 默认 7890）

#### 页面 3：设备配置

- 选择 CSV 文件
- 下拉选择 `deviceId`
- 显示该设备 token 是否存在
- 服务器地址，默认 `https://www.petpaint.top`
- CUPS 队列名，默认 `cp1500`
- 如果该设备已被使用，阻止继续
- 可选：选择要绑定的商户（后续版本）

#### 页面 4：执行

- 实时日志
- 步骤进度：
  1. 连接 SSH
  2. 上传离线包
  3. 配置 WiFi
  4. 安装依赖
  5. 安装/编译 Gutenprint
  6. 创建 CUPS 队列
  7. 写入 agent.json
  8. 启动服务
  9. 验证心跳
  10. 验证 WiFi 出网
- 成功提示：可以拔网线并重启
- 失败提示：显示最后 50 行日志和排查建议

### 6.2 扫描设备实现

优先级从高到低：

1. **UDP 广播发现（推荐）**
   - N1 上运行 `petpaint-discover.service`，监听 UDP 50000。
   - EXE 向 `255.255.255.255:50000` 广播。
   - N1 回复 JSON：

     ```json
     {
       "device_id": "dev_xxx",
       "hostname": "petpaint-abc123",
       "ip": "192.168.1.50",
       "model": "n1",
       "configured": true
     }
     ```

   - EXE 聚合结果并展示。
   - 优点：换 IP、换路由器都能找到。

2. **局域网 TCP 22 扫描（兜底）**
   - 根据 PC 的网卡地址计算 `/24` 网段。
   - 并发探测 22 端口，读取 SSH banner。
   - 过滤出 Armbian/OpenSSH 设备。
   - 优点：N1 还没装发现服务时也能用。
   - 缺点：可能扫到其他设备，需要用户确认。

3. **mDNS（可选）**
   - N1 主机名 `petpaint-<deviceId后6位>`。
   - `ping petpaint-abc123.local`。
   - Windows 对 mDNS 支持不稳定，不作为主方案。

### 6.3 EXE 技术选型

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| .NET WPF + SSH.NET | Windows 原生、单文件、体积小 | 需要 C# 开发 |
| Python + PySide6 + Paramiko + PyInstaller | 开发快、脚本复用方便 | 打包体积大、杀软误报概率略高 |

建议第一版用 **.NET WPF + SSH.NET**，如果更熟悉 Python 就用 Python。

## 7. N1 端 provision.sh

### 7.1 职责

1. 检查 root 权限。
2. 设置主机名：`petpaint-<deviceId后6位>`。
3. 配置 WiFi：
   - 商户 WiFi 优先级 300
   - 家里 WiFi 优先级 200
   - 手机热点优先级 100
   - 全部 `autoconnect yes`
4. 生成本地 apt 源，安装 CUPS、Pillow 和编译依赖。
5. 没有 CP1500 PPD 时编译安装 Gutenprint 5.3.5。
6. 检测 CP1500 USB 地址，创建 CUPS 队列 `cp1500`。
7. 复制 `print-agent` 到 `/opt/print-agent`。
8. 写入 `agent.json`，权限 600。
9. 安装并启动 `print-agent.service`。
10. 安装 `petpaint-discover.service`。
11. 验证：
    - `systemctl is-active print-agent`
    - `lpstat -p cp1500`
    - 心跳请求成功
    - `ping -I wlan0` 能出网
12. 输出日志到 `/tmp/petpaint-provision.log`，完成后写 `/tmp/petpaint-provision.done`。

### 7.2 幂等要求

- 脚本可以重复执行。
- 已安装的包跳过。
- 已有 WiFi 配置时更新，不重复创建。
- 已有 `agent.json` 时覆盖为当前设备配置。
- 失败时保留日志，不删除现场配置。

### 7.3 长任务处理

Gutenprint 编译可能很久，EXE 不要一直占用 SSH 会话：

```bash
nohup bash /tmp/petpaint-provision.sh > /tmp/petpaint-provision.log 2>&1 &
```

EXE 定时读取日志，轮询 `/tmp/petpaint-provision.done`。

## 8. 离线安装包

### 8.1 目录结构

```text
petpaint-offline/
├─ debs/                     # arm64 .deb
├─ gutenprint-5.3.5.tar.xz
├─ print-agent/
├─ provision.sh
├─ petpaint-discover.py
├─ petpaint-discover.service
└─ agent.json                # 每台设备不同
```

### 8.2 依赖包清单

```text
cups
cups-client
cups-daemon
python3-pil
build-essential
pkg-config
gettext
libtool
libcups2-dev
libcupsimage2-dev
libusb-1.0-0-dev
libglib2.0-dev
xz-utils
ca-certificates
dpkg-dev
```

### 8.3 生成离线包

#### 方式 A：先用一台能上网的 N1 下载（最准确）

```bash
sudo apt-get update
sudo apt-get install --download-only -y \
  cups cups-client cups-daemon python3-pil \
  build-essential pkg-config gettext libtool \
  libcups2-dev libcupsimage2-dev libusb-1.0-0-dev \
  libglib2.0-dev xz-utils ca-certificates dpkg-dev
```

包在：

```text
/var/cache/apt/archives/
```

拷回电脑：

```powershell
scp -r root@N1的IP:/var/cache/apt/archives ./offline/debs
```

下载 Gutenprint：

```bash
wget -O /tmp/gutenprint-5.3.5.tar.xz \
https://downloads.sourceforge.net/project/gimp-print/gutenprint-5.3/5.3.5/gutenprint-5.3.5.tar.xz
```

#### 方式 B：电脑 Docker 下载 arm64 包

先确认 N1 的版本：

```bash
cat /etc/debian_version
dpkg --print-architecture
```

电脑上：

```powershell
docker run --rm --platform linux/arm64 -v ${PWD}/offline/debs:/out arm64v8/debian:bookworm bash -c "
apt-get update &&
apt-get install -y --download-only \
  cups cups-client cups-daemon python3-pil \
  build-essential pkg-config gettext libtool \
  libcups2-dev libcupsimage2-dev libusb-1.0-0-dev \
  libglib2.0-dev xz-utils ca-certificates dpkg-dev &&
cp /var/cache/apt/archives/*.deb /out
"
```

Debian 版本必须和 N1 一致，架构必须是 `arm64`。

### 8.4 N1 上本地安装

```bash
cd /tmp/petpaint-offline
dpkg-scanpackages debs /dev/null | gzip -9c > debs/Packages.gz

sudo tee /etc/apt/sources.list.d/petpaint-local.list <<'EOF'
deb [trusted=yes] file:/tmp/petpaint-offline/debs ./
EOF

sudo apt-get update
sudo apt-get install -y \
  cups cups-client cups-daemon python3-pil \
  build-essential pkg-config gettext libtool \
  libcups2-dev libcupsimage2-dev libusb-1.0-0-dev \
  libglib2.0-dev xz-utils ca-certificates
```

### 8.5 编译 Gutenprint

```bash
cd /tmp/petpaint-offline
tar -xJf gutenprint-5.3.5.tar.xz
cd gutenprint-5.3.5
./configure --without-doc
make -j$(nproc)
sudo make install
sudo ldconfig
sudo systemctl restart cups
```

装完再执行 `setup.sh`，它会检测到 CP1500 驱动并跳过下载。

## 9. WiFi 配置

### 9.1 创建配置

```bash
sudo nmcli connection add type wifi con-name "商户WiFi" ifname wlan0 ssid "商户WiFi名称"
sudo nmcli connection modify "商户WiFi" wifi-sec.key-mgmt wpa-psk wifi-sec.psk "商户WiFi密码"
sudo nmcli connection modify "商户WiFi" connection.autoconnect yes connection.autoconnect-priority 300
```

家里 WiFi 优先级 `200`，手机热点 `100`。

隐藏 SSID 追加：

```bash
sudo nmcli connection modify "商户WiFi" 802-11-wireless.hidden yes
```

### 9.2 优先级

| WiFi | 优先级 |
| --- | --- |
| 商户 WiFi | 300 |
| 家里 WiFi | 200 |
| 手机热点 | 100 |

数字越大越优先。前一个不可用时，NetworkManager 会尝试下一个。

### 9.3 验证

```bash
nmcli device status
nmcli connection show
ip addr show wlan0
ping -I wlan0 -c 3 www.petpaint.top
```

`ping -I wlan0` 能通，才说明 WiFi 真能出网。此时默认路由可能还在网线上，不能只看 `ping` 是否通。

### 9.4 安全提醒

- 家里 WiFi 和手机热点密码留在商户设备上，设备丢失或退回时会泄露。
- 建议家里 WiFi 使用访客网络。
- 发货前可选：把家里 WiFi 和热点设为 `autoconnect no`，不删除配置，需要时再打开。
- 手机热点建议 2.4GHz；iPhone 打开「最大兼容性」。

## 12. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| Armbian 首次登录强制改密 | SSH 自动化卡住 | 先手动登录完成一次 |
| root 禁止 SSH | EXE 无法直接登录 | 用普通用户 + sudo，EXE 处理 sudo 密码 |
| Gutenprint 下载失败 | 安装中断 | 离线包内置源码，本地编译 |
| .deb 架构/版本不匹配 | 依赖装不上 | 确认 arm64 + Debian 版本，本地 apt 源 |
| CP1500 未接 | CUPS 队列建不出来 | 配置阶段就接打印机并开机 |
| WiFi 未验证就拔网线 | 设备离线 | `ping -I wlan0` 通过后再拔 |
| 家里/热点密码泄露 | 安全风险 | 访客网络；发货前设 autoconnect no |
| 两个设备同 token | 任务被抢 | 每台新建设备，不复用线上 token |
| eMMC 写入过多 | 寿命下降 | 日志 tmpfs、关闭 swap、noatime |
| 断电导致服务异常 | 设备离线 | systemd 自启、watchdog、重启测试 |
| EXE 误操作 | 配错设备 | CSV 行标记已用，执行前二次确认 |
| 日志泄露 token/密码 | 安全风险 | 日志脱敏，不记录敏感字段 |
