# 现场设备配置手册（树莓派 / N1 + CP1500 打印机）

> 这份手册写给第一次上门装设备的同学：不需要懂电脑，照着一步一步做就行。
> 每一步都写了「你要做什么」和「你应该看到什么」。看到的不一样，就停下来，看第 9 章或拍照发群里问，**不要自己乱试**。

---

## 0. 开始前，先记住 4 条规矩

1. 设备令牌（一长串字母和数字）等于店主账号的钥匙。**只能填进盒子里，不许发到群里、不许截图给别人。**
2. 盒子怕摔、怕静电。拿的时候托住外壳，不要用手直接摸电路板上的金属部分。
3. 看不懂的英文，先拍照发群，不要乱按、不要关窗口、不要拔电源。
4. 店里的路由器、网线、监控都不要碰。只动我们自己的盒子和打印机。

---

## 1. 先弄懂我们要干什么（30 秒看懂）

我们要把一个「没有屏幕的小电脑」（盒子）装到店里，让它 24 小时连着店里的 WiFi，顾客在网站付款后，它就指挥打印机把照片打印出来。

一共 5 大步：

| 步骤 | 在哪里做 | 做什么 |
| --- | --- | --- |
| 第 1 步 | 店里 | 给空白盒子装系统（用你的笔记本电脑） |
| 第 2 步 | 店里 | 让盒子连上店铺 WiFi，找到它的「门牌号」（IP） |
| 第 3 步 | 店里 | 用电脑远程进入盒子 |
| 第 4 步 | 店里 | 复制一段命令，让盒子自己装好打印程序 |
| 第 5 步 | 店里 | 把盒子和这家店绑定，测试打印，验收 |

本手册出现的 4 个词，先认识一下：

- **树莓派 / N1**：就是那个小盒子，一台没有屏幕的小电脑。
- **SD 卡 / 内存卡**：盒子的「硬盘」，系统装在它里面。
- **IP 地址**：盒子在店里的「门牌号」，长得像 `192.168.1.23`。
- **终端（黑色窗口）**：用打字的方式指挥盒子的地方。不要怕，我们只输入手册里给的命令。

## 2. 出发前：东西带齐了吗

### 2.1 硬件

- [ ] 树莓派 4B（或 N1 盒子）一台
- [ ] 树莓派电源（5V 3A，圆头）／ N1 电源（12V）
- [ ] 16GB 以上的 SD 卡 + 读卡器（N1 用 U 盘/读卡器刷机也一样）
- [ ] CP1500 打印机 + 打印机电源线
- [ ] 打印机 USB 线（一头方口插打印机，一头扁口插盒子）
- [ ] 相纸、色带（让店主提前买好，现场确认有纸）
- [ ] 笔记本电脑（Windows 10/11）+ 充电器
- [ ] 手机（能开热点、能装 App）
- [ ] 记号笔、标签贴纸

### 2.2 出发前在办公室先确认

- [ ] 笔记本电脑能正常上网，能打开 `https://www.petpaint.top`
- [ ] 店主已经把店铺 WiFi 名称和密码发给你，并且这个 WiFi **能上网**（不是只有内网）
- [ ] 店主已经用商家账号登录过后台，知道怎么进入「信息维护」
- [ ] 你的手机热点能正常上网（备用，如果店铺 WiFi 有问题）

### 2.3 现场一定要记录的信息

准备一张纸或手机备忘录，记下：

## 3. 第 1 步：给空白盒子装系统（在店里用笔记本操作）

> 为什么要在店里做？因为系统里要写进「这家店的 WiFi 名称和密码」，到了店里才知道。

### 3.1 安装刷机软件（笔记本上操作）

1. 打开浏览器，搜索 `Raspberry Pi Imager`，进入官网下载 Windows 版。
2. 双击下载好的安装包，一路点「下一步 / 安装 / 完成」。
3. 安装完成后，在开始菜单找到 `Raspberry Pi Imager`，打开它。

> N1 盒子不用这个软件，看第 10 章的单独说明。

### 3.2 选系统和 SD 卡

1. 点第一个按钮「选择操作系统」→ 选 `Raspberry Pi OS (64-bit)`（列表第一个带推荐字样的）。
2. 点第二个按钮「选择存储卡」→ 选你的 SD 卡（看容量认，别选错成你的 U 盘）。
3. 点右下角「下一步」。

### 3.3 填写设置（最关键的一步，别跳）

弹出一个「编辑设置」的窗口，点它，然后按下面填：

**「常规」这一页：**

| 项目 | 填什么 |
| --- | --- |
| 设置主机名 | `petpaint-店铺拼音`，例如 `petpaint-xiaohuajia`（只能用小写字母、数字、横杠） |
| 设置用户名 | `pi` |
| 设置密码 | `Pass0001` |
| 配置无线局域网 | 无线局域网国家选 `CN`，名称填店铺 WiFi 名，密码填店铺 WiFi 密码 |
| 设置区域设置 | 时区选 `Asia/Shanghai`，键盘布局选 `us` |

**「服务」这一页：**

- 把「开启 SSH」打勾；
- 下面选「使用密码认证」。

填完点「保存」，再点「是 / 写入」。

### 3.4 等待写入

1. 弹窗问「是否确定要擦除」，点「是」。
2. 开始写入，进度条走完后会显示「写入成功」。
3. 点「继续」，把 SD 卡从读卡器里拔出来。

> 如果写入过程中报错，重新插一次读卡器再写一次；连续两次失败就换一张 SD 卡。

### 3.5 组装并开机

1. 盒子断电状态下，把 SD 卡插进盒子卡槽（听到「咔」一声）。
2. 打印机 USB 线：方口插打印机，扁口插盒子任意 USB 口。
3. 接 HDMI 可以先不接，我们用电脑远程看它。
4. 最后插盒子电源，通电开机。
5. 盒子上的绿灯会闪一会儿，**不要拔电**，让它自己启动。

---

## 4. 第 2 步：找到盒子的 IP（门牌号）

等盒子开机后（大约 1～3 分钟），做下面任意一种：

### 方法一：用手机找（推荐，最简单）

1. 手机连上**同一个店铺 WiFi**。
2. 在应用商店搜索并安装 `Fing`（免费）。
3. 打开 Fing，点「扫描 / Scan」。
4. 在设备列表里找一个名字是 `petpaint-xxxx` 的设备，点开，记下它的 `IP 地址`，例如 `192.168.1.23`。

### 方法二：用电脑找

1. 笔记本连上店铺 WiFi。
2. 按键盘上的 `Win` 键（田字键），输入 `cmd`，回车，会弹出一个黑色窗口。
3. 输入下面这行（把 `xiaohuajia` 换成你填的店铺拼音），回车：

```
ping petpaint-xiaohuajia.local
```

4. 如果显示 `来自 192.168.x.x 的回复`，那个地址就是 IP。
5. 如果显示「找不到主机」，就用方法一。

> 两种方法都找不到：先确认盒子电源灯是亮的、店铺 WiFi 密码没填错。还不行就进第 9 章。

---

## 5. 第 3 步：用电脑远程进入盒子

1. 确保笔记本连着**同一个店铺 WiFi**。
2. 按 `Win` 键，输入 `cmd`，回车，打开黑色窗口。
3. 输入下面这行，把 IP 换成你刚才记下的：

```
ssh pi@192.168.1.23
```

4. 第一次连接会问 `Are you sure you want to continue connecting (yes/no)?`
   输入 `yes`，回车。
5. 接着显示 `pi@192.168.1.23's password:`，输入密码 `Pass0001`。
   **注意：输密码时屏幕上什么都不会显示，这是正常的**，输完直接回车。
6. 看到类似 `pi@petpaint-xiaohuajia:~ $` 的字样，说明你进到盒子里了。

> 提示 `Permission denied`：密码错了，重新输一次，注意大小写。
> 提示 `Connection refused` 或一直卡住：盒子没连上网，回第 4 章重新找 IP。

---

## 6. 第 4 步：让盒子自己装好打印程序

现在你已经在盒子里了，**按顺序**复制下面每一行，粘贴到黑色窗口，按回车：

```
git clone https://github.com/Marshall1111/Prompt-Reference-Board.git
```

```
mv ~/Prompt-Reference-Board/print-agent ~/print-agent
```

```
cd ~/print-agent
```

```
sudo ./setup.sh
```

说明（不用记，知道在干嘛即可）：

- 第 1 行：把我们的程序从网上下载到盒子里；
- 第 2 行：把打印程序放到固定位置 `~/print-agent`；
- 第 3 行：进入这个文件夹；
- 第 4 行：开始自动安装。会要一次密码，输入 `Pass0001`。

> 怎么粘贴？在黑窗口里点**鼠标右键**就是粘贴。或者在窗口标题栏右键 → 编辑 → 粘贴。
>
> 如果执行第二行时提示 `mv: cannot move ...`（文件夹已存在），说明之前做过一次，直接执行第三行 `cd ~/print-agent` 继续即可。

接下来屏幕上会滚动大量英文，**这是正常的，不要关窗口、不要按 Ctrl+C**。

安装过程中会多次出现 `Do you want to continue? [Y/n]` 之类的提问，直接按回车（默认是继续）。

看到最后出现：

```
==> 完成
```

就说明装好了。中间如果下载失败（出现 `下载失败` 或 `error`），重新执行一次 `sudo ./setup.sh` 即可，装过的步骤会自动跳过。

---

## 7. 第 5 步：把盒子和这家店绑定

这一步要店主的账号配合，请店主拿手机或电脑做，你在旁边指导。

### 7.1 店主在后台创建设备

1. 打开 `https://www.petpaint.top`，用**商家账号**登录。
2. 进入「信息维护」（或商户工作台里的设备管理）。
3. 找到「打印设备」，点「新增设备」。
4. 队列名保持默认 `cp1500`，设备名称可以填「店里打印机」。
5. 保存。列表里会出现一条新设备，状态先是「离线」，正常。

### 7.2 复制「配置命令」

1. 在新设备那一行，点「复制配置命令」。
2. 这时店主手机/电脑的剪贴板里已经有了一段很长的命令。

### 7.3 把命令贴进盒子

这一步**只能在盒子的黑色窗口里做**，所以：

- 如果命令复制在店主的手机上：用微信把这段文字发给你自己（**注意：这段包含令牌，只发给你自己的电脑，不要发群、不要发朋友圈**），然后你在笔记本上复制，再在黑色窗口里右键粘贴，回车。
- 如果店主就在你旁边用电脑：直接在他的电脑上按 `Win` 键 → `cmd` → `ssh pi@盒子IP` → 输密码，再粘贴。

粘贴后按回车，等 10 秒左右，没有任何报错就成功了。

### 7.4 确认服务在运行

在黑色窗口输入：

```
systemctl is-active print-agent
```

回车，应该显示：

```
active
```

## 8. 第 6 步：验收（必须做完才能走）

### 8.1 检查打印机队列

在黑色窗口输入：

```
lpstat -p cp1500
```

应该显示类似 `printer cp1500 is idle`（空闲）。如果显示 `disabled`，输入 `sudo cupsenable cp1500` 再查一次。

### 8.2 检查后台是否在线

让店主刷新后台设备列表，应该变成：

- 状态：**在线**
- 打印机：**准备好了**

如果 1 分钟后还是离线，看第 9 章。

### 8.3 打一张测试

两种方式，任选一种：

- 让店主用自己账号下一单最便宜的现场制作订单并付款，确认能自动出纸；
- 或者你在黑色窗口输入下面命令，会打一张校准页（会消耗 1 张相纸）：

```
python3 print_agent.py calibrate
```

看到打印机开始进纸、出纸，就算通过。一张纸大约需要几十秒，耐心等，不要重复点。

### 8.4 验收清单

- [ ] 后台显示设备在线、打印机「准备好了」
- [ ] 测试页能正常出纸，画面完整、颜色正常
- [ ] 纸张数量、色带余量告诉店主
- [ ] 把盒子贴在打印机旁边固定好，线不会绊到人
- [ ] 拍 3 张照片存档：①盒子接线全貌 ②后台设备在线页面 ③测试打印成品
- [ ] 在盒子外壳贴上标签：店铺名 + 设备 ID + 配置日期
- [ ] 告诉店主：**盒子不要断电、不要拔 USB 线、不要改 WiFi 密码**；如果改了 WiFi 密码要联系你

## 9. 常见问题（照着查，不要慌）

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| `ping petpaint-xxx.local` 找不到主机 | 电脑不支持这种名字查找 | 改用手机 Fing 找 IP |
| 手机 Fing 里也找不到盒子 | 盒子没连上 WiFi / WiFi 密码填错 | 重新刷卡，仔细核对 WiFi 名称和密码（大小写、空格） |
| `ssh` 提示 `Connection refused` | 盒子还没启动完，或 SSH 没开 | 等 2 分钟再试；还不行重新刷卡并确认勾选了「开启 SSH」 |
| `ssh` 提示 `Permission denied` | 密码输错 | 重新输 `Pass0001`，注意大小写，输入时不显示是正常的 |
| `git clone` 失败 / 卡住 | 店铺网络不稳定或被限制 | 换你的手机热点重试 |
| 安装到一半出现 `下载失败` | 下载 Gutenprint 失败 | 重新执行 `sudo ./setup.sh` |
| 提示 `没有找到 CP1500 的 PPD` | 驱动没装好 | 重新执行 `sudo ./setup.sh`，装完会自动跳过已完成的步骤 |
| `没有发现 USB 打印机` | USB 线没插好 / 打印机没开机 | 检查两头插紧、打印机电源打开，然后重新执行 `sudo ./setup.sh` |
| 后台一直显示离线 | 盒子没网 / 令牌贴错 / 服务没启动 | 在盒子里执行 `systemctl status print-agent --no-pager`，看红色报错；按 `q` 退出 |
| 服务反复重启 | `agent.json` 里的地址或令牌不对 | 让店主重新点「复制配置命令」，重新粘贴一次 |
| 打印没反应，但后台显示已打印 | 打印机没纸 / 色带装错 / 卡纸 | 检查相纸和色带，重装后让店主点「重试打印」 |
| 打印出来是白纸 | 相纸放反（光泽面朝下） | 按打印机说明书重新装纸 |
| 打印很慢、一张要等很久 | 正常现象，CP1500 是热升华，一张要几十秒 | 告诉店主耐心等，不要重复下单 |
| 打印出来四周有白边 | 属于排版边界，先记录，回来反馈 | 在验收记录里写「有白边，约 X mm」，拍照 |
| 盒子被碰掉电了 | — | 重新插电，等 2 分钟，后台恢复在线即可，不用重装 |
| 店里的 WiFi 密码改了 | 盒子连不上网 | 需要重新刷卡填写新密码（或联系技术同学远程处理） |

> 如果排查 3 次还不行，停止操作，拍视频发群：拍盒子指示灯、拍线怎么插的、拍黑色窗口最后 10 行文字。

## 10. N1 盒子单独说明（和树莓派不一样的地方）

N1 不能刷 Raspberry Pi 系统，要用 Armbian，步骤多一些。**第一次做 N1，建议先在办公室跟着技术同学做一遍。**

1. 在电脑上安装 `balenaEtcher`，用它把 Armbian 的 `.img` 文件写进 U 盘/SD 卡。
2. 插到 N1 上，接电源开机，接 HDMI 显示器（N1 没有网口配置界面，第一次必须接显示器和键盘）。
3. 第一次开机是黑底白字，会要求：
   - 设置 root 密码：输入 `Pass0001`，再输一次；
   - 选择默认 shell：直接回车；
   - 创建普通用户：用户名输入 `pi`，密码 `Pass0001`，其他直接回车。
4. 登录后输入下面命令连 WiFi（会弹出蓝色文字界面，用方向键选择）：

```
sudo nmtui
```

   选「Activate a connection」→ 选店铺 WiFi → 输入密码 → 按 Esc 退出。

5. 记下 N1 的 IP：在上面界面里能看到，或者用手机 Fing 找 `armbian` / `n1`。
6. 后面从第 3 步开始完全一样，命令照抄。

N1 装驱动会比树莓派慢一些，屏幕长时间不动是正常的，别关窗口。

## 11. 名词小抄

| 名词 | 用大白话说 |
| --- | --- |
| 终端 / 命令行 / 黑色窗口 | 打字指挥电脑的地方 |
| SSH | 用一根网线「隔空」进入另一台电脑 |
| IP 地址 | 设备在 WiFi 里的门牌号 |
| 主机名 | 设备给自己起的名字，例如 `petpaint-xiaohuajia` |
| 队列 / cp1500 | 盒子里给打印机排队的名字，固定用 `cp1500` |
| 令牌 / token | 一长串密码，证明这台盒子属于这家店 |
| 驱动 | 让电脑认识打印机的「翻译软件」 |
| 服务 / print-agent | 一直在后台跑的小程序，负责领任务、送打印 |

## 12. 绝对不要做的事

- 不要把设备令牌发到任何群、朋友圈、小红书，也不要截图。
- 不要用店主的电脑安装任何东西，只用自己的笔记本。
- 不要动店里的路由器、光猫、网线、监控。
- 不要拆盒子外壳，不要拔 SD 卡。
- 不要在打印过程中拔电源或 USB 线。
- 不要把盒子的 WiFi 改连到你自己的热点后就走人（除非店主同意临时测试）。
- 配置完成后不要立刻离开，等测试打印真正出纸再走。
