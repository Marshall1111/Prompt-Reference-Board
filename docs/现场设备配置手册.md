# 现场设备配置手册（N1 / 树莓派 + CP1500，EXE 版）

> 这份手册写给上门装设备的同学：不需要懂 Linux，照着 EXE 的提示一步一步做即可。
> 每一步都写了「你要做什么」和「你应该看到什么」。看到的不一样，就停下来，看第 8 章或拍照发群里问，**不要自己乱试**。
>
> 本手册按新方案编写：N1 系统跑在 eMMC，不再刷 U 盘启动；设备由后台「设备库存」预先创建，现场用 EXE 配置。
> EXE 已完成（`PetpaintProvisioner.exe`），按第 4～6 章操作；第 10 章是 EXE 故障时的手动兜底。

---

## 0. 开始前，先记住 4 条规矩

1. 设备令牌（一长串字母和数字）等于店主账号的钥匙。**只能填进盒子里，不许发到群里、不许截图给别人。**
2. 盒子怕摔、怕静电。拿的时候托住外壳，不要用手直接摸电路板上的金属部分。
3. 看不懂的英文或报错，先拍照发群，不要乱按、不要关窗口、不要拔电源。
4. 店里的路由器、网线、监控都不要碰。只动我们自己的盒子、打印机和网线。

---

## 1. 先弄懂我们要干什么（30 秒看懂）

我们要把一个「没有屏幕的小电脑」（盒子）装到店里，让它 24 小时连着店里的 WiFi，顾客在网站付款后，它就指挥打印机把照片打印出来。

新方案一共 5 大步：

| 步骤 | 在哪里做 | 做什么 |
| --- | --- | --- |
| 第 1 步 | 出发前 | 后台「设备库存」创建设备，导出 CSV，准备 EXE 和离线包 |
| 第 2 步 | 店里 | 给盒子接电源、网线、打印机 USB，开机 |
| 第 3 步 | 店里 | 打开 EXE，扫描设备、登录、配置店铺 WiFi |
| 第 4 步 | 店里 | 选择 CSV 里的设备，一键安装并验证 |
| 第 5 步 | 店里 | 拔网线、重启、后台绑定、测试打印、验收 |

本手册出现的词，先认识一下：

- **N1 / 树莓派**：就是那个小盒子，一台没有屏幕的小电脑。
- **eMMC / SD 卡**：盒子的「硬盘」。N1 用 eMMC，树莓派用 SD 卡。
- **Armbian**：N1 上运行的系统，类似电脑上的 Windows。
- **IP 地址**：盒子在店里的「门牌号」，长得像 `192.168.1.23`。
- **SSH**：用网线「隔空」进入盒子的方式，EXE 会自动做，不需要你手敲。
- **EXE**：我们自己的 Windows 配置工具，负责扫描盒子、配 WiFi、装打印程序。
- **离线包**：EXE 自带的一套安装文件，不依赖店里网络下载。
- **令牌 / token**：一长串密码，证明这台盒子属于这家店。
- **队列 / cp1500**：盒子里给打印机排队的名字，固定用 `cp1500`。

## 2. 出发前：东西带齐了吗

### 2.1 硬件

- [ ] N1 盒子一台（卖家已把 Armbian 装在 eMMC 里）
- [ ] N1 电源（12V，原装或同规格）
- [ ] 网线一根
- [ ] CP1500 打印机 + 打印机电源线
- [ ] 打印机 USB 线（一头方口插打印机，一头扁口插盒子）
- [ ] 相纸、色带（让店主提前买好，现场确认有纸）
- [ ] Windows 10/11 笔记本电脑 + 充电器
- [ ] 手机（能开热点，备用）
- [ ] 可选：HDMI 线 + USB 键盘（首次登录、救急用）
- [ ] 记号笔、标签贴纸

> N1 不需要 U 盘启动，也不需要现场刷机。系统已经在 eMMC 里。

### 2.2 出发前在办公室先确认

- [ ] 电脑能正常上网，能打开 `https://www.petpaint.top`
- [ ] 后台「设备库存」已经创建好这台设备，并导出 CSV
- [ ] CSV 里有 `deviceId` 和 `token`，且这台设备没有被其他盒子使用
- [ ] EXE 和离线包是最新版本，并且在同一台办公设备上跑通过
- [ ] 店主已经把店铺 WiFi 名称和密码发给你，并且这个 WiFi **能上网**
- [ ] 你的手机热点能正常上网（备用，建议 2.4GHz）
- [ ] 如果这是替换旧设备：旧设备已经停止、后台已解绑

## 3. 第 1 步：现场接线

### 3.1 接盒子

1. 盒子先断电。
2. 网线一头插盒子网口，一头插店里路由器的 **LAN 口**（不是 WAN 口）。
3. 打印机 USB 线：方口插打印机，扁口插盒子 USB 口。
4. 打印机电源插上，打开打印机。
5. 最后插盒子电源，通电开机。
6. 盒子指示灯会闪一会儿，**不要拔电**，等 1～3 分钟。

> 重要：**打印机必须在 EXE 安装前就接好并开机**。否则盒子里建不出打印队列，后面会失败。

### 3.2 不要做的事

- 不要插 U 盘去「启动系统」，新方案不需要。
- 不要拆盒子外壳，不要拔 eMMC/SD 卡。
- 不要动店里的路由器、光猫、监控。

## 4. 第 2 步：EXE 扫描并登录

### 4.1 打开 EXE

1. 笔记本连上**和盒子同一个路由器**的 WiFi。
2. 双击打开 EXE。
3. 点击「扫描设备」，等几秒（会遍历本机所在 /24 网段）。
4. 列表里会列出所有开放 SSH 的机器，格式是「IP / 名称 / SSH 版本」，例如：
   - `192.168.31.197  armbian  SSH-2.0-OpenSSH_9.2p1 Debian-2+deb12u3`
   - 名称优先取路由器注册的主机名（N1 一般显示 `armbian`）；取不到显示 `—`，连过一次之后会自动记住并回填
5. 双击目标行，IP 会自动填到右侧「IP 地址」，光标跳到密码框。

### 4.2 如果扫描不到

按顺序试：

1. 确认笔记本和盒子连的是同一个路由器。
2. 确认盒子网线插在路由器 LAN 口，网口灯在闪。
3. 直接在「IP 地址」输入框里手动填 IP，去路由器后台的 DHCP 客户端列表找盒子 IP。
4. 手机装 Fing，扫局域网，找 `armbian` / `n1` / `petpaint-xxxx`。
5. 还找不到，接 HDMI + USB 键盘，登录盒子执行 `ip addr` 看 IP。

### 4.3 登录盒子

1. 选择或输入盒子 IP。
2. 填 Armbian 用户名和密码：
   - 卖家可能给的是 `root`，也可能是 `armbian` 或 `pi`
   - 默认密码常见是 `1234`，但卖家通常改过，优先问卖家
3. 点「连接」。EXE 会自动接受 SSH 主机指纹，不会弹确认框。
4. 连上后右侧会显示主机名、系统版本、架构、根分区、打印机是否识别；架构不是 arm64 会直接告警。
5. 如果提示「首次登录需要修改密码」，先用 HDMI + 键盘或 SSH 手动完成一次，再回 EXE。

> 密码输入时不显示是正常的。连续输错会被临时锁定，不要反复试。

## 5. 第 3 步：配置 WiFi

### 5.1 查看和修改店铺 WiFi

第一步连接成功后，「2. 配置 WiFi」页会**自动读取盒子里已有的 WiFi**，列出连接名、WiFi 名称、优先级、是否隐藏 SSID、当前状态（已连接 / 备用）。

1. 点表格里的某一行，下方表单会自动填入这条 WiFi 的名称、密码、优先级。
2. 改完点「保存修改」，修改会立即写入盒子。
3. 新增：在表单里填 WiFi 名称、密码，优先级填 `300`，点「新增」。会自动建一条名为 `petpaint-<WiFi名称>` 的连接。
4. 如果是隐藏 WiFi，勾选「隐藏 SSID」。
5. 删除：选中要删的那条，点「删除选中」。
6. 想确认盒子最新的状态，点「重新读取」。

### 5.2 可选：添加测试 WiFi

如果你需要在自己家或办公室测试，可以再加两条：

| WiFi | 优先级 | 用途 |
| --- | --- | --- |
| 店铺 WiFi | 300 | 商户现场 |
| 家里 WiFi | 200 | 办公室/家里测试 |
| 手机热点 | 100 | 现场备用 |

- 手机热点建议开 **2.4GHz**；iPhone 打开「最大兼容性」。
- 不需要的 WiFi 可以不加。
- 家里 WiFi 和热点密码会保存在盒子里，设备丢失或退回时会泄露；建议家里用访客网络。

### 5.3 测试通过的标准

第 3 步执行完，EXE 日志里会出现这一行：

```text
wlan0 -> petpaint 200
```

`200` 表示盒子已经通过 WiFi 访问到服务器；如果日志写的是 `WiFi 已连接但无法通过 wlan0 访问服务器`，就是没通。

技术同学也可以手动验证：

```bash
curl --interface wlan0 -sS -m 20 -o /dev/null -w '%{http_code}\n' https://www.petpaint.top
```

> 此时网线还插着，默认路由可能还在网线上，所以不能只看普通 `ping`，必须指定 `wlan0`。
> **WiFi 没测试通过之前，不要拔网线。**

## 6. 第 4 步：选择设备并执行

### 6.1 选择设备

1. 「设备 CSV」右边点「浏览」，选择出发前从后台导出的 CSV。
2. 在「设备 ID」下拉里选中这台盒子对应的 `deviceId`（CSV 里有几个设备就有几个选项）。
3. 确认右侧 token 显示为掩码，而不是「未选择」。
4. 确认「服务器」是 `https://www.petpaint.top`，「队列名」是 `cp1500`。
5. 没接打印机时勾选「跳过打印机（未接 CP1500）」，接了就不要勾。
6. 离线包路径会自动指向 EXE 同目录的 `offline/petpaint-offline-*.tgz`，一般不用改。

### 6.2 开始执行

1. 点「开始配置」。
2. EXE 会自动：
   - 上传离线包
   - 配置 WiFi
   - 安装 CUPS、Pillow、Gutenprint
   - 创建 `cp1500` 队列
   - 写入 `agent.json`
   - 启动 `print-agent`
   - 验证心跳和 WiFi
3. 过程中会滚动日志，**不要关 EXE、不要拔盒子电源、不要拔打印机 USB**。
4. 安装可能比较久（几分钟），进度条和日志长时间不动是正常的。
5. 配置脚本在盒子里用 `setsid nohup` 独立运行，EXE 断开也不会中断配置；重新点「开始配置」会重跑一遍，脚本可重复执行，不会重复安装。
6. 结束后可以点「测试打印」验证出纸，点「重启盒子」验证冷启动后能否自动恢复接单。

### 6.3 成功的样子

EXE 显示全部通过，至少包括：

- `print-agent` 正在运行
- `cp1500` 队列存在且空闲
- 后台心跳成功
- WiFi 测试通过

## 7. 第 5 步：验收

### 7.1 拔网线并重启

1. 确认 WiFi 测试已经通过。
2. 拔掉盒子上的网线。
3. 在 EXE 里点「重启盒子」，或者断电再上电。
4. 等 1～2 分钟，让盒子连 WiFi、启动服务。

### 7.2 确认后台在线

1. 打开 `https://www.petpaint.top`，用管理员账号登录。
2. 进入「设备库存」。
3. 找到这台设备，状态应该变成「在线」。
4. 如果还是离线：
   - 等 1 分钟刷新
   - 检查盒子 WiFi 是否真的连上
   - 检查 token 是否选错
   - 看第 8 章

### 7.3 绑定商户

1. 后台「设备库存」找到这台设备。
2. 点「绑定商户」，选择对应商户。
3. 或者进入商户「信息维护」→「打印设备」→「绑定已有设备」。
4. 绑定后，商户工作台应该能看到设备在线。

> 如果是替换旧设备：先解绑旧设备，再绑定新设备，不要让两个盒子同时绑同一个商户。

### 7.4 测试打印

两种方式，任选一种：

- 优先用 EXE 里的「测试打印」按钮；
- 如果 EXE 还没有测试按钮，让技术同学在盒子里执行校准页（会消耗 1 张相纸）。

看到打印机进纸、出纸，画面完整，就算通过。一张纸大约几十秒，耐心等，不要重复点。

### 7.5 验收清单

- [ ] 后台显示设备在线、打印机「准备好了」
- [ ] 测试页能正常出纸，画面完整、颜色正常
- [ ] 拔掉网线后仍能通过 WiFi 在线
- [ ] 断电重启后能自动上线
- [ ] 纸张数量、色带余量告诉店主
- [ ] 盒子固定在打印机旁边，线不会绊到人
- [ ] 拍 3 张照片存档：①盒子接线全貌 ②后台设备在线页面 ③测试打印成品
- [ ] 在盒子外壳贴标签：店铺名 + 设备 ID + 配置日期
- [ ] 告诉店主：**盒子不要断电、不要拔 USB 线、不要改 WiFi 密码**；改了 WiFi 密码要联系你

## 8. 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| EXE 扫描不到盒子 | 不在同一路由器 / 网线没插好 / 防火墙 | 确认同一局域网；手动填 IP；检查网口灯 |
| `ssh` 提示 `Permission denied` | 用户名或密码错 | 问卖家要账号；注意大小写；不要反复试 |
| 提示首次登录要改密码 | Armbian 首次登录 | 接 HDMI + 键盘，或先用 SSH 手动改一次 |
| WiFi 测试失败 | 密码错 / 热点是 5GHz / 隐藏 SSID 没勾 | 核对密码；热点切 2.4GHz；勾选隐藏 SSID |
| 提示「没有发现 USB 打印机」 | 打印机没开机 / USB 没插好 | 检查两头插紧、打印机开机，然后重新执行 |
| 提示「没有找到 CP1500 的 PPD」 | Gutenprint 没装好 | 检查离线包是否完整；重新执行配置 |
| 安装中途失败 | 离线包缺文件 / 架构不匹配 | 看日志最后 50 行；确认 arm64 和 Debian 版本 |
| 后台一直离线 | WiFi 没连上 / token 错 / 服务没启动 | 重新插网线，执行 `systemctl status print-agent` |
| 服务反复重启 | `agent.json` 地址或令牌不对 | 回后台核对 token，重新执行配置 |
| 打印没反应，但后台显示已打印 | 没纸 / 色带错 / 卡纸 | 检查相纸和色带，重装后重试 |
| 打印出来是白纸 | 相纸放反 | 按打印机说明书重新装纸 |
| 拔网线后离线 | WiFi 没有真正连上 | 重新插网线，执行 `ping -I wlan0` 测试 |
| 改 WiFi 后 SSH 卡住 | 切换网络时 SSH 自然断开 | 正常现象，等 20 秒用新 IP 重连 |
| EXE 中途关闭 | 电脑休眠 / 误关 | 重新打开 EXE，配置脚本可重复执行 |

> 如果排查 3 次还不行，停止操作，拍视频发群：拍盒子指示灯、拍线怎么插的、拍 EXE 最后 20 行日志。

## 9. N1 盒子单独说明

N1 和树莓派不一样，重点记住：

1. **系统在 eMMC 里**，卖家已经装好 Armbian，不需要 U 盘启动，也不需要现场刷机。
2. 第一次登录可能要求改密码。改完记好，后面 EXE 要用。
3. 如果 SSH 没开，接 HDMI + USB 键盘登录后执行：

   ```bash
   sudo systemctl enable --now ssh
   ```

4. 如果 HDMI 没画面，先换 HDMI 线或电视的另一个口，等 30 秒再看。
5. N1 只有两个 USB 口：一个接键盘（调试时），一个接打印机；配置完成后键盘可以拔掉。
6. N1 电源是 12V，不要用错电源。
7. 手机热点建议 2.4GHz；iPhone 打开「最大兼容性」。
8. 不要拔 eMMC，不要尝试从 U 盘启动。

## 10. 手动兜底（EXE 未完成或故障时）

> 这一章给技术同学看，现场同学不要自己操作。

### 10.1 手动上传离线包

电脑上：

```powershell
scp -r .\petpaint-offline root@盒子IP:/tmp/petpaint-offline
```

盒子上：

```bash
cd /tmp/petpaint-offline
sudo bash provision.sh
```

### 10.2 手动联网安装（仅限有外网/代理）

```bash
git clone https://github.com/Marshall1111/Prompt-Reference-Board.git
cd Prompt-Reference-Board/print-agent
sudo ./setup.sh \
  --server-url https://www.petpaint.top \
  --device-id dev_xxx \
  --device-token xxx
```

### 10.3 手动验证

```bash
systemctl status print-agent
lpstat -p cp1500
journalctl -u print-agent -n 50 --no-pager
```

## 12. 名词小抄

| 名词 | 用大白话说 |
| --- | --- |
| 终端 / 命令行 / 黑色窗口 | 打字指挥电脑的地方 |
| SSH | 用一根网线「隔空」进入另一台电脑 |
| IP 地址 | 设备在 WiFi 里的门牌号 |
| 主机名 | 设备给自己起的名字，例如 `petpaint-xiaohuajia` |
| eMMC | N1 盒子里的「硬盘」 |
| Armbian | N1 上运行的系统 |
| 队列 / cp1500 | 盒子里给打印机排队的名字，固定用 `cp1500` |
| 令牌 / token | 一长串密码，证明这台盒子属于这家店 |
| 驱动 | 让电脑认识打印机的「翻译软件」 |
| 服务 / print-agent | 一直在后台跑的小程序，负责领任务、送打印 |
| EXE | 我们的 Windows 配置工具 |
| 离线包 | 不依赖店里网络的一套安装文件 |
