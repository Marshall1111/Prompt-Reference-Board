# 商户自定义打印

在网页商户工作台点击“自定义打印”。店主和店员都可以使用，打印不扣钱包、不增加订单收益。

1. 上传JPG、PNG或WebP，每张最多40MB，每页最多10张源图。
2. 设置图片宽高，单位毫米。在固定比例框中单指移动、双指缩放，框内就是实际打印内容。
3. 确认裁切后在100×148毫米相纸上排版。单指移动、双指旋转，也可用90度按钮和角度输入；图片尺寸保持固定。
4. 可复制图片，最多24个图片实例。不能重叠或越界，放不下的图片会保留在待排列表，不会进入打印版面。
5. 查看最终预览，选择1～20份后提交。浅灰裁切线沿图片四边延伸到纸边，隐藏在所有图片矩形区域下方，包括透明图片，不覆盖图片内容。

任务显示在工作台原有任务列表中。失败时先检查设备和实际出纸份数，再核对已完成份数并重试剩余份数。网络中断前正在出纸的一份可能尚未回报，系统不会自动重新打印自定义任务。

如果实际已全部出纸，填写全部份数后点击“确认已全部打印”，任务会标记成功，不再出纸。

## 升级设备

自定义任务需要升级店内的 `agent.py` 和 `print_agent.py`。普通订单仍沿用自动排版。

- 更新服务器和这两个代理文件；使用新版安装脚本，或在设备实际安装目录覆盖文件后重启 `print-agent.service`。
- CP1500的 `config.json` 使用105.67×158.5毫米驱动页面，现有102×150毫米出血区域的中心与100×148毫米实际相纸中心一致。自定义版面按100×148放入，不扩大到出血区域。
- `agent.json` 的 `lp_options` 应为 `["-o", "PageSize=Postcard", "-o", "StpBorderless=True", "-o", "print-scaling=none"]`。新版 `setup.sh` 和 `provision.sh` 会写入这些选项。
- 代理心跳上报 `supportedLayoutModes`，验证纸张配置后才包含 `custom-sheet-v1`；旧代理不能领取自定义任务。等待工作台设备状态更新后再提交。
- 离线部署包中的两个代理文件和安装脚本也应同步更新，避免新安装设备仍运行旧代理。

运行 `python tools/update-print-offline-bundle.py --directory print-agent/offline` 可更新并校验现有离线包中的代理与安装脚本，保留Linux依赖。配置工具的 `build.ps1` 在复制离线包前会自动执行同步。

服务器文件保存在私有的 `data/custom-prints/`，包含源图、版面快照和最终图片。服务器升级时必须保留该目录，与 `data/orders.sqlite` 一起备份；普通配置备份不包含这些打印文件。

## 验证

```powershell
node --test tests/custom-print.test.mjs
node tests/custom-print-server.mjs
python -m unittest discover -s print-agent -p test_custom_print.py
npm run build
npm run test:custom-print:browser
```

浏览器验证需要本机已安装Microsoft Edge，运行前先执行构建；测试使用独立的临时商户数据，不连接真实账户或打印机。

实机验收使用50×74毫米测试图和旋转图片，核对实际尺寸、相纸位置与辅助线。设备排版单独验证可运行 `python print_agent.py custom-sheet sheet.png --save driver-page.jpg`，该命令只生成驱动页面，不出纸。
