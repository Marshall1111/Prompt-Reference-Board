# 宝宝认知书默认提示词（审阅稿）

更新日期：2026-07-21
适用范围：`/book` 新创建的认知书。已创建的任务保留其创建时的提示词；用户单独重新生成时仍可在页面中修改。

## 设计原则

- 仅将上传照片用作宝宝身份参考：保持五官、肤色、年龄感和发型，不复制参考照的服装或背景。
- 除颜色、职业外，每一页也必须有独立的“服装 + 身体位置 + 动作 + 小道具”指令；禁止复用参考照服装、泛化的站立/挥手姿势或相同姿势。
- 所有页面均为 1:1、0–3 岁中英双语认知内容，采用 **DK children's encyclopedia style**：白色或暖米白留白页面、儿童百科编辑版式与白底抠图拼贴构图。
- 视觉为真实细腻的宝宝摄影与少量剪贴感插画结合；使用柔和暖光、自然肤质、细白描边、轻微纸张纹理。
- 避免复杂场景、景深、杂物、多人、拼贴宫格、水印、边框、3D 动画感与不相关物品。
- 模型生成的画内文字可能偶有失真；前端会同时展示清晰的卡片名称和状态，便于操作。

## 内页双语短句规则

- 身体：`This is my {英文部位}. 这是我的{中文部位}。` 或当前页面已有的自然动作短句。
- 职业：`I can be a {职业}. 我可以成为{职业中文}。`
- 颜色：`This is {颜色}. 这是{颜色中文}。`
- 情绪：`I feel {情绪}. 我感到{情绪中文}。`
- 交通：`This is a {交通工具}. 这是一辆{交通工具中文}。`
- 动物：`Hello, {动物}! 你好，{动物中文}！`
- 日常：`I can {动作}. 我会{动作中文}。`
