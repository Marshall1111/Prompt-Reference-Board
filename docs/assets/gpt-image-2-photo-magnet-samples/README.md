# GPT Image 2 Photo Magnet Samples

This directory stores final sample outputs for the photo-magnet style-transfer prompt handbook.

Source photos are intentionally not committed here. Each sample should be generated from a user-provided person, pet, group, or person-and-pet photo, then referenced from `../../gpt-image-2-photo-magnet-style-transfer-prompts.md`.
