.env 图片供应商测试工具

独立本地工具：页面只读取你手动选择的 .env，并通过本机 Node 代理调用供应商接口。密钥只在本机浏览器与代理之间传递，不会发送到项目服务器。

1. 选择环境文件

尚未选择 .env 文件

先在本目录运行 node env-provider-tester-server.mjs，再打开 http://127.0.0.1:8787。推荐在 Chrome 或 Edge 中使用；浏览器支持文件系统访问时会直接覆写所选文件，否则会下载更新后的 .env。

2. 选择或填写供应商

3. 测试

生图测试会消耗供应商额度。

连通性测试会请求 /models，用于检查网络、地址和鉴权。Images 路线在未选择参考图时调用 /images/generations，选择参考图后调用 /images/edits。部分中转站未开放 /models 时可直接继续进行生图测试；只有成功返回图片后才会允许写入。
