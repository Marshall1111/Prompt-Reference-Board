## 强烈合并建议

### 1. 可爱 3D 动画

合并来源：1、2

建议保留：`style_1779181030715` 或预览图更稳定的一条。

原因：两条提示词完全相同，标签也基本一致，生成结果差异只来自随机性。

建议统一提示词：

```text
转绘成可爱的 3D 皮克斯动画风格，保留主体的关键外形、表情和姿态，柔和光照，圆润造型，毛发蓬松自然，整体干净、温暖、适合儿童动画视觉。
```

### 2. 装饰儿童平面插画

合并来源：5、6、25

建议保留：5 或 25。5 的描述更通用；25 的蓝底和手写文字更强烈，适合作为变体。

原因：三者都强调平面化、儿童感、粗线条、明快色彩、装饰符号。6 是 5 的英文同义版本。

建议统一为：

```text
装饰性儿童平面插画，保留主体和大致构图，将细节简化为干净的平面形状，使用大胆俏皮的高饱和色彩、粗糙抖动的黑色手绘轮廓、花朵/爱心/星星等童趣装饰。整体像手工绘制在纸上的儿童绘本插画，可爱、松弛、略带不完美感。避免写实光影、复杂纹理和精细渲染。
```

### 3. 搞笑丑萌涂鸦

合并来源：10、13、14、15、22、24

建议保留：13 或 15 作为主体提示词，10/24 的“街头贴纸、neo-naive pop”可作为增强描述。

原因：这些风格都生成夸张表情、廉价马克笔/蜡笔线条、糟糕透视、卡通背景、网络表情包感。14 过于简短，22 与 15 高度同义，10 与 24 高度同义。

建议统一为：

```text
把照片转绘成搞笑丑萌涂鸦插画：像用廉价马克笔或蜡笔快速画出的草图，线条凌乱粗糙，比例和透视故意有点笨拙，主体表情略夸张但不要恶意丑化。使用高饱和平涂色彩、细黑轮廓和可见笔触，加入简单卡通背景、随机涂鸦符号、贴纸感小元素和少量手写文字。整体幽默、松散、网络表情包气质，避免写实、精修和 3D 质感。
```

### 4. 极简照片拼贴 / 冰箱贴卡片

合并来源：20、21

建议保留：20。21 可作为“泛主体/旅行合影”变体。

原因：两者结构几乎相同，都是上下分区：下半保留照片，上半提取主体做冰箱贴式小图标，再加简洁文字。

建议统一为：

```text
根据真实照片生成上下分区的极简摄影卡片，比例 3:4。下半部分保留原图不修改；上半部分使用从照片中提取的主色作为纯色背景，并将最有识别度的主体元素转化为一个简约精致的冰箱贴式图标，带轻微立体感、浅色描边和投影。图标居中偏上，尺寸小巧，周围保留大量留白，下方加入一行优雅日期或短句。整体清爽、干净、明亮，避免复杂拼贴、乱码文字和过度卡通化。
```

4. 最后统一标签命名，避免同一类风格分散在“手绘、涂鸦、随意、丑萌、儿童、插画”等过多近义标签里。

## 标签整理建议

建议把标签拆成几类固定维度，而不是所有描述词都混在同一层：

| 维度 | 推荐标签示例 |
| --- | --- |
| 风格大类 | 3D、平面插画、涂鸦、线稿、海报、像素、拼贴、油画 |
| 气质 | 可爱、丑萌、复古、怪诞、儿童、极简 |
| 用途 | 宠物、头像、摄影卡片、旅行、手帐 |
| 技法 | 蜡笔、马克笔、平涂、半色调、厚涂、速写 |

这样后续搜索会更稳定，也能减少“看起来差不多但标签不同”的重复入口。
